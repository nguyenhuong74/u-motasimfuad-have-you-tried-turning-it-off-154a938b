# Have You Tried Turning It Off?

One funny single-line reply from a hopeless tech support agent to a desperate customer:

> "Great news — I've restarted your ticket, so as far as the system is concerned, your computer is fixed. Fancy a coffee while reality catches up?"

## The joke

The classic support move is restarting the customer's computer — so this agent restarts the *ticket* instead. The system now believes the problem is solved, the computer is still broken, and the agent is cheerfully offering coffee while "reality catches up". The humour is all in the agent's confident uselessness; the customer is never mocked, just left waiting with a smile and a beverage suggestion.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (no trailing newline). The output is deterministic: every run produces byte-identical output.
